# docs-bugs

Registro de bugs e problemas complicados encontrados durante o desenvolvimento, com
diagnóstico e solução. Serve como memória técnica para evitar re-investigar a mesma classe
de problema e para entender decisões não-óbvias.

## Convenção

- Um arquivo por problema: `AAAA-MM-DD-titulo-curto-em-kebab-case.md`.
- Estrutura sugerida: **Sintoma → Diagnóstico → Causa raiz → Correção → Observações**.
- Citar os arquivos e linhas relevantes.
